`nai_text_sign_initial.json` / `nai_text_dialogue_initial.json` 保留初轮记录。初轮测试错误地假定 writer 总是第二次调用、且必须原样输出占位符；实际匿名角色有既有候选调用，writer 也会直接输出正确引号原文。测试改为定位 lettering writer，并接受原样引号文字的保护路径；仍核对实际最终 prompt 与逐人归属。

`nai_text_negative_pairing_failure.json` 是另一轮的真实失败记录：单人举牌被模型错误写成孤立的 `source#holding_sign`，配对修复后仍无对端，因此既有校验正确拒绝。没有启用原生文字通道，也没有放松互动配对。隔离反例改用人物旁边静置的空白牌以专门检查不写字的边界。这一失败不能被后续文字用例成功抹去。

新增文字指引与旧职责的对应：普通七字段 / 实例 JSON、英文 tags / 原语言 prose、人数和身份、衣柜和外貌权限、可见性、位置与动作方向全部沿用；只追加文字的原文、位置、表面、说话人和可读空间职责。原文在视觉过滤后恢复，最终 `Text:` 由宿主生成，转换只处理此前的视觉权重。无新增正常模型调用、OCR 或自动图片重试。

同一工作区还有其他任务的空间构图、坐标与 NAI 扩展请求改动；本次保留它们，不把这些差异算作文字通道的实现。
