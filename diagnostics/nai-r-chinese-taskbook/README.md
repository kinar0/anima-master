## 翻译边界

仅将说明性英文翻译为自然中文，并调整句内语序和段落，使其便于阅读。没有借用普通七字段模板中 `-r` 原文没有的规则，也没有把 JSON 改为七字段。

JSON 键名、方向前缀、性别／人数语法、身份与服装 canonical tags、权重、画布数值、角色锚点、原文请求和原有示例均保留。JSON 示例里解释字段用途的占位字符串译为中文，字段名、层级、类型与示例坐标不变。动态锚点中的 `identity / wardrobe / clothing / source / changes` 和枚举值继续原样保留，避免把证据协议误当说明文翻译。

原来重复出现的用户原文、分散在 system／正文中的重复要求、身份复核、可见性、自审、构图分析和位置理由全部保留。本次也未清理参考资料中的 `自然 => nature`、服装组件候选或其他可疑数据：翻译不改变现有证据。

本样例没有启用原生文字、额外条件角色参考、图生图、色气或扶她条件块，也没有触发修复调用。**本草稿不冒充这些分支的完整中文模板**；这些分支及现有修复任务书保持原状，若后续接入中文版本，应另行逐项翻译、对照。这里只提供这次实际任务的完整中文消息，未进行全路径模板替换。
